# Route the current question once

A known destination needs no router. When unsure, `ripwire <dir> --help-task="<task>"` recommends one command with evidence or abstains; it does not execute or authorize the recommendation. Choose the present authorized phase, not every activity the overall project will eventually require.

| Current need | Owner |
| --- | --- |
| Cold repository/subsystem or several files for one question | `ripwire-orient` |
| Known symbol, use-site, body, literal, or call path | `ripwire-navigate` |
| Symptom, failure, trace, or suspected regression | `ripwire-find-bug` |
| A multi-symbol feature/interface plan | `ripwire-before-you-build` |
| One symbol to write or existing behavior to reuse | `ripwire-reuse-first` |
| Quality of code just changed or a measured refactor | `ripwire-quality-bar` |
| Merge safety, changed contract, affected tests, or branch landing | `ripwire-change-check` |
| Maintenance risk in code not written in this task | `ripwire-fresh-eyes` |
| Existing code genuinely needing tests | `ripwire-write-tests` |
| A measured runtime/performance problem | `ripwire-perf-target` |
| Authorized security review or subsystem handoff | `ripwire-security-scan` or `ripwire-handoff` |

Enter only that owner and its conditionally required resources. Reuse complete unchanged instructions already present in retained context. Real context loss can require authority and code-state recovery; a synthetic continuation or another named symbol does not restart cold orientation.

For an uncommon verb, boundary, or routing ambiguity, consult the relevant row of [routing-reference.md](routing-reference.md). Graph expressions, architecture enforcement, and MCP operation are resources for their actual questions, not automatic companion skills. A source-implementation phase does not authorize standalone test migration or evidence work.

The two code-change reflexes remain: reuse before writing a symbol and an authorized one-shot quality delta before declaring it done. A clean leaf result stops; later drill-down, tests, acknowledgements, notes, baselines, exports, and hooks require their conditions and task authority. Structural metrics are not runtime measurements, and a served body does not override a whole-file reading requirement.

These definitions are maintained in `~/agentic-skills`. Use `$manage-ripwire-skills` after upstream changes and `$link-agentic-skills` for separately authorized distribution. Do not run the upstream `skills/install.sh` to replace this family. Hook and MCP registration remain separate effects.
