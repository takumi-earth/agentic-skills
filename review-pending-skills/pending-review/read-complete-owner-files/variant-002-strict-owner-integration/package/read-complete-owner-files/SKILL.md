# Read Complete Owner Files

Use the active strict-work owner to select and consume complete source evidence.

Read [the strict owner integration](references/strict-owner-read-integration.md) when a direct-reading requirement is active.

## Route the evidence contract

- `$guard-strict-work` records the explicit direct-reading requirement and selects the semantic owner boundary.
- `$plan-strict-work` reads every selected planning source through EOF before closing ownership or architecture decisions.
- `$implement-strict-work` reuses completed unchanged reads and rereads only owner files changed since the plan or diagnosis.
- `$reconcile-live-steering` freezes the next conclusion when a user strengthens the evidence contract mid-work.
- `$resume-strict-context` supplies range/hash bookkeeping after compaction without turning summaries into authority.

## Preserve the invariant

- Batch metadata for the complete selected file set before body reads.
- Read one file and one bounded non-overlapping range per result through EOF.
- Resume only from the first unconfirmed line after truncation.
- Use search matches only for navigation after each selected owner is complete.
- Invalidate only changed hashes.
- Report complete files and incomplete ranges precisely; do not claim ownership understanding from a search excerpt.

## Stay proportional

Do not create a durable source audit, enumerate a repository, or reread completed files unless the user requests it or the current ownership decision genuinely depends on it. This skill does not grant source edits, verification, Git, delegation, or cross-repository authority.
