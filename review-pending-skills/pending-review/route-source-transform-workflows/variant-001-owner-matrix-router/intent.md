# Owner-matrix-router variant

## Concrete intent

Route multi-owner source-transformation work without circular handoffs or ownership collapse.

## Approach

Map protected authority, rollout reasoning, current-source inventory, production transform design, adaptive test design, and removed-test parity to distinct existing skills, with a primary owner and artifact for each question.

## Preserved nuance

Routing does not grant phase authority or create a new source of truth. Specialist owners retain their contracts, and the router performs no implementation or verification.

## Relationships and uncertainty

This overlaps six official owners whose local handoffs may already be sufficient. Review should keep the router only if mixed tasks demonstrably loop or under-trigger.
