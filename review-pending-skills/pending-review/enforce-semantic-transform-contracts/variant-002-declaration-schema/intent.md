# Declaration-schema variant

## Concrete intent

Make missing semantic transformation contract fields mechanically visible before implementation begins.

## Approach

Bundle a JSON schema and deterministic validator for stable identity, typed owner, complete scope, semantic query, load-bearing precondition, minimal rewrite, postcondition, cardinality, hint miss behavior, typed outcomes, transaction order, and behavioral evidence links.

## Preserved nuance

The validator checks declaration completeness and forbidden authority shapes only. It cannot prove that a query resolves the intended symbol or that a rewrite is semantically correct.

## Relationships and uncertainty

This is an executable alternative to the instruction-only variant and overlaps `$design-semantic-source-transforms`. Review should decide whether declarative contracts fit enough patch engines to justify a reusable schema.
