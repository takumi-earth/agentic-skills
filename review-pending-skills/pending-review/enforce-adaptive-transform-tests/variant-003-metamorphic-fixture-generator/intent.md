# Metamorphic-fixture-generator variant

## Concrete intent

Generate a repeatable adaptation matrix from one minimal semantic fixture model rather than copied upstream before-and-after bodies.

## Approach

Derive trivia, line shift, reorder, file movement, module movement, extension, decoy, ambiguity, real drift, recognized post-state, replay, and irrelevant-version cases with typed expectations and stable IDs.

## Preserved nuance

Generated cases are inputs, not proof. Product-owner behavior and typed structural outcomes still require executable assertions, and no generated full-source snapshot becomes the oracle.

## Relationships and uncertainty

This complements `$test-adaptive-source-transforms` and the opaque harness variant. Review should decide how much language-specific syntax belongs in adapters.
