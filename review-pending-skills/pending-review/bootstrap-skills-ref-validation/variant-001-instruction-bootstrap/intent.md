# Instruction-bootstrap variant

## Concrete intent

Resolve and verify a repository-pinned `skills-ref` toolchain without confusing distribution, module, CLI, source, dependency, or helper execution identities.

## Approach

Perform bounded repository discovery, inspect package metadata, separate installation authority, verify provenance after authorized installation, invoke Python helpers through Python, and report canonical and harness gates independently.

## Preserved nuance

Missing tooling does not authorize environment mutation or broad home-directory search. A missing executable bit on a Python script is not a sandbox condition.

## Relationships and uncertainty

This overlaps system `$skill-creator` and repository validation guidance. Review should decide how much canonical-layout specificity belongs in a portable skill.
